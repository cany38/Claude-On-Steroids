    How to connect claude.ai
    
    
  
    
  
    About two minutes, once. After that you only open this panel to approve what Claude wants to change.
    

  
      
    
    1. 
      
      Copy your connector URL
      
      
      This is the address claude.ai uses to reach this computer. It contains a secret key, so treat it like a password.
      
      
      The URL appears here once the tunnel is open (a few seconds after start).
      
    
      2. 
    
    2. 
      
      Add it in claude.ai
      
      
        
        
      1. Open claude.ai, then Settings > Connectors, and switch to the Yours tab.
        2. 
        
      2. Press Add, then Add custom connector.
        3. 
        
      3. Name: Claude On Steroids. URL: paste the address you copied.
        4. 
        
      4. Under Authentication choose No sign-in (claude.ai marks it "Detected"). Leave the OAuth client options as they are.
        5. 
        
      5. claude.ai warns: "Without sign-in, anyone with the server URL can use this connector." That is expected. The URL itself is the key, and every write, delete and command still waits for your approval in this panel.
        6. 
        
      6. Press Add.
        7. 
      
      
    
      3. 
    
    3. 
      
      Press Connect, then allow the tools
      
      
        
        
      1. Next to the new connector press Connect.
        2. 
        
      2. Open the connector. Under Tool permissions set Read-only tools to Always allow.
        3. 
        
      3. Set Write/delete tools to Always allow as well.
        4. 
      
      
      
      Otherwise claude.ai stops and asks before every single call. Your real safety net is here: the panel still holds writes, deletes and commands for your approval, at the level you choose under Permissions.
      
    
      4. 
    
    4. 
      
      Try it in a chat
      
      
      Start a new chat, make sure Claude On Steroids is switched on in the chat's connector menu, and write: run the machine_info tool. When the call arrives, the top of this panel turns to claude.ai connected.
      
    
      5. 
    
    5. 
      
      Day to day
      
      
        
        
      • Keep the black console window open: closing it stops the connector.
        • 
        
      • When Claude wants to write, delete or run a command, an amber card appears at the top of this panel. Approve or deny it there; it waits about 110 seconds.
        • 
        
      • Access decides which folders Claude can see at all. Keep it to the project you are working on.
        • 
      
      
    
      6. 
    
    6. 
      
      Keep the same URL after a restart
      
      
      The free quick tunnel gets a new address every time the app starts, so you would paste a new URL into claude.ai each time. Press Get a permanent address under the Connector URL once: sign in to a free Cloudflare account and click Allow. A new account can take a little while to activate; the panel switches by itself and shows Permanent. Paste that URL into claude.ai one last time.
      
    
      7. 
    
    7. 
      
      If something is off
      
      
        
        
      • claude.ai says the connector is unavailable: the app is not running, or the URL changed. Start it with the start file for your system and compare the URL in claude.ai with the one here.
        • 
        
      • "Session not found": the app restarted. Switch the connector off and on in the chat.
        • 
        
      • The URL leaked: press Rotate address under Connection, then paste the new URL into claude.ai.
